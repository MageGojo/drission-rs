# 运行时分层 · Browser / HTTP / AI / Task

> 目标:把「所有能力往 `Browser` / `Tab` 上堆」改成四层运行时 + 一等公民 Context / Profile。
> 现有 `Browser` / `Tab` / `Element` API **全部保留**,新类型是其上的编排层,不是替换。
>
> 授权边界与 README 一致:仅用于你拥有或已获明确授权的系统。Profile / Context
> 用来管理**自有账号与测试身份**,不是用来绕过网站安全控制。

## 为什么拆

浏览器自动化真正难的不是 `tab.click()` / `tab.input()`,而是同时管几百、几千个
账号身份(Cookie / Storage / Proxy / UA / 时区)以及它们的网络观测。

如果继续把 Context / Profile / 拦截策略塞进巨大的 `Browser` 类,池、CLI、MCP
都会变成同一坨。分层之后:

```
                 drission-rs
                      │
       ┌──────────────┼──────────────┐
       ↓              ↓              ↓
 Browser Runtime   HTTP Runtime    AI Runtime
       │              │              │
      CDP          reqwest        MCP
    Camoufox       impersonate    JSONL
       │              │              │
       └──────────────┼──────────────┘
                      ↓
                 Task Runtime
                      │
             Pool / Retry / Proxy
             Profile / Session
             Checkpoint
```

| 运行时 | 职责 | 现有落点 | 新增一等公民 |
|---|---|---|---|
| Browser Runtime | 进程、标签、元素、CDP/Juggler | `cdp/` / `browser/` | `BrowserContext` |
| HTTP Runtime | 无浏览器 HTTP、TLS 指纹、cookie 交接 | `session/` / `net` | 统一 `NetRequest` / `NetResponse` |
| AI Runtime | snapshot / markdown / MCP / JSONL | `ai_snapshot` / `drs` | 不改协议,只认层 |
| Task Runtime | 池、重试、代理、断点、身份盘 | `pool/` / `identity-*` | `ProfileManager` / `PoolLease` |

代码入口:`src/runtime/mod.rs` 按层再导出,方便读架构;实现仍按后端分目录。

## 一等公民:BrowserContext

模型:

```
BrowserPool  →  Browser  →  BrowserContext  →  Tab
                    │              │
                 Profile        Cookie / Storage
                 (磁盘)         Proxy / UA / TZ
```

```rust
let browser = pool.acquire().await?;
let context = browser.context("account_001").await?;
let tab = context.new_tab().await?;
```

Context 负责(CDP `Target.createBrowserContext` + 会话级 Emulation):

- Cookie / Cache(原生隔离)
- localStorage / sessionStorage(经 `storage_state`,同源写入)
- Proxy / UA / Timezone / Locale
- extra HTTP headers
- Permissions
- Viewport

同一 `name` 在同一浏览器进程内复用同一个 CDP context,关 Context 才 `disposeBrowserContext`。
`Tab::close` **不会**拆掉它所属的命名 Context(池里 `new_tab_with` 的一次性隔离 context 仍随 tab 回收)。

IndexedDB 完整导入导出不在本批(Chrome user-data-dir / Profile 磁盘已含;协议级 dump 后续再补)。

## Profile Manager

磁盘布局(每个账号一份,跨进程复用登录态):

```
profiles/
├── user_001/
│   ├── manifest.json    # proxy / UA / locale / timezone / screen / args / headers
│   ├── chrome/          # Chromium user-data-dir(Cookie / LocalStorage / IDB / Cache)
│   └── .lock            # 同 profile 同时只允许一个浏览器
├── user_002/
└── ...
```

```rust
let profiles = ProfileManager::open("profiles")?;
let lease = profiles.acquire("user_001").await?;
let browser = lease.launch().await?;
let ctx = browser.context("user_001").await?;
```

`acquire` 做文件锁,避免两个 worker 抢同一份 user-data-dir。
这是**库级**磁盘身份;CLI `identity-job` 的 lease / cooldown / ledger 仍是调度 sidecar,
两者互补:库管「这份目录怎么启动」,CLI 管「这个账号现在能不能跑」。

## 网络层门面

旧 API(`tab.listen()` / `tab.intercept()` / `har_record` / `route_from_har`)保留。
新门面把过滤和动作收成一条链:

```
网页 → Request → Interceptor → allow | block | modify | mock
                 Listen      → NetRequest + NetResponse
                 Record/Replay → HAR
```

```rust
tab.network().filter("/api/").method("POST").listen().await?;
tab.network().filter("/ads/").block().await?;
tab.network().filter("/api/me").mock(200, vec![], r#"{"ok":true}"#).await?;
tab.network().filter("/api/").rewrite(ResumeOptions::new().url("https://stub/local")).await?;
let har = tab.network().record().await?;
```

## 不做什么

- 不把项目产品化成「绕过网站安全控制」的工具。
- 不拆掉现有 `Browser` / `Tab` / `listen` / `intercept` / `identity-*`。
- 本批默认后端 = CDP;Camoufox 端 Context / Profile / network 门面后续对齐。
- 不把 CLI 身份治理(ledger / cooldown / risk)再实现一遍。
