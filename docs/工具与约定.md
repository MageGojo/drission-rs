# 工具与约定（drission-rs）

## CLI / MCP

- 二进制：`drs`（`crates/drission-cli`，与库同一版本，默认 feature `cdp`）
- 开发构建：`cargo build -p drission-cli --bin drs --release`
- 安装：`cargo install --path crates/drission-cli --bin drs` 或 `cp target/release/drs ~/.cargo/bin/drs`
- 改完 CLI/MCP 后必须 **`drs stop` 再 `drs ensure-serve`**，否则旧 daemon 不认新命令；Cursor MCP 需重载以刷新工具列表
- 产品命令：`drs browser` / `tab` / `context` / `profile` / `network` / `record` / `replay` / `pdf` / `inspect` / `console` / `download`（`open`=`tab open`）
- MCP server id：`user-drs`。默认 `core` 含 `browser_network` / `browser_console` / `browser_download`，抓 XHR **不必**改 `DRS_MCP_TOOLS`
- PDF / inspect / record / 旧 `network_*` 要 `DRS_MCP_TOOLS=browser|all`
- AI 配方（怎么选命令）见 [`产品级CLI.md`](产品级CLI.md)；字段见 [`CLI.md`](CLI.md)
- Agent 必读 skill：仓库 `.cursor/skills/drs-browser/SKILL.md`，本机副本 `~/.claude/skills/drs-browser/SKILL.md`（改一边必须同步）

## AI 读页（首选）

```bash
drs --json snapshot          # 大纲 + refs + markdown(htmd)
drs --json markdown          # 只要 Markdown
# MCP: browser_snapshot → browser_click({ref:"e1"}) / browser_type({ref:"e2", text:"..."})
```

HTML→Markdown 用 Rust 库 `htmd`（`src/html_md.rs`）。设计见 [`AI页面快照.md`](AI页面快照.md)。

## 防卡退环境变量

| 变量 | 默认 | 含义 |
|---|---|---|
| `DRS_MCP_TIMEOUT_MS` | 60000 | MCP 单次工具调用超时 |
| `DRS_DAEMON_TIMEOUT_MS` | 60000 | CLI→daemon RPC 读响应超时 |

## 浏览器后端

- 默认：**Chromium / CDP**（本机 Chrome，找不到下 Chrome for Testing）
- 可选：**Camoufox / Juggler**（`--features camoufox`）
- 可选引擎变体：**Lightpanda**（仍是 CDP，同一套 `Browser`/`Tab`；**只在库里用**）
  - 库：`Browser::launch(BrowserOptions::new().lightpanda())`
  - `drs` 不接 Lightpanda（本机 Agent / MCP 继续用 Chrome）
  - 二进制：`LIGHTPANDA_BIN` / `DRISSION_LIGHTPANDA` → 可执行文件旁边 → PATH → 缓存 → GitHub nightly
  - 设计与边界见 [`Lightpanda.md`](Lightpanda.md)；Zig/Rust 复刻判断见 [`分析-Lightpanda能否用Rust复现.md`](分析-Lightpanda能否用Rust复现.md)
  - 公开示例：`cargo run --example own_site`（本地页，再打开 apizero.cn 文档页）

## 库架构(运行时分层)

四层入口:`drission::runtime::{browser, http, ai, task}`。
一等公民 Context / 磁盘 Profile / 网络门面见 [`运行时分层.md`](运行时分层.md)。
Agent 编排(observe / 语义定位 / wait / capture)见 [`Agent运行时.md`](Agent运行时.md)。

```rust
let page = tab.agent();
page.observe().await?;
page.find("登录按钮").click().await?;
tab.wait().element("#dash").visible().timeout(Duration::from_secs(10)).await?;
tab.wait().network().idle().timeout(Duration::from_secs(10)).await?;
tab.wait().popup().timeout(Duration::from_secs(5)).await?;
tab.capture().html().await?;
let ctx = pool.acquire_context("account_001").await?;
```

```rust
let ctx = browser.context("account_001").await?;
let tab = ctx.new_tab(None).await?;
tab.network().filter("/api/").method("POST").listen().await?;
```
