# 后端能力矩阵 · CDP(默认)vs Camoufox 对照

> 本库有两个浏览器后端:**默认 = Chromium / CDP**，可选 = **Camoufox / Firefox**。
> 公开示例只测本地页和 [apizero.cn](https://apizero.cn/)。对照表见下文。
>
> 相关文档:[标配补齐.md](标配补齐.md)、[法律风险.md](法律风险.md)。

图例:✅ 有 · — 无 · ⚠️ 部分 / 有差异。

---

## 1. 两后端都有(对称核心)

日常自动化的骨架能力两端一致,同一套上层写法在两个后端都能跑。

| 能力 | CDP | Camoufox | 备注 |
|---|:---:|:---:|---|
| 启动 / WS 接管(headful / headless) | ✅ | ✅ | CDP 走 Chromium,Camoufox 走 Firefox Juggler |
| 导航(`get` / 前进后退 / 重载) | ✅ | ✅ | |
| 执行 JS(`run_js`) | ✅ | ✅ | 返回 `serde_json::Value` |
| 元素定位(`css:` / `xpath:`)、点击、输入 | ✅ | ✅ | 定位器语义对齐 DrissionPage |
| 截图(元素 / 整页) | ✅ | ✅ | `screenshot(&ShotOpts)` 两端同签名 |
| cookies 读写 | ✅ | ✅ | `cookies()` / 设置 |
| 每上下文隔离(`new_tab_with` + `ContextOverride`) | ✅ | ✅ | 均新建独立 BrowserContext;proxy/UA/locale/时区两端可覆盖(CDP 原生 per-context 代理) |
| 并发池 | ✅ | ✅ | CDP `ChromiumPool` / Camoufox `BrowserPool`;每任务轮换出口 + 指纹 |
| 指纹池(`FingerprintPool`) | ✅ | ✅ | 预设 profile 轮换,后端无关 |
| 监听 / 拦截入口(`listen()` / `intercept()` 构建器) | ✅ | ✅ | 两端都有构建器;Camoufox 另有扁平显式句柄(见 §3) |
| 验证码 OCR(`tab.ocr_image`) | ✅ | ✅ | 需 `--features ocr`;`set_default_ocr` 热替换槽**后端无关**,两端读同一槽(见 [OCR模型热替换.md](OCR模型热替换.md)) |
| 无障碍语义快照(`ax_snapshot`,DOM 派生) | ✅ | ✅ | `role "name"` 语义树,跑 JS 近似算法;两端一致(CDP 另有原生版 `ax_tree`,见 §2) |
| 吐环境 / 补环境(`dump_env`) | ✅ | ✅ | 各自 `EnvDumper` |
| 过盾(Cloudflare 等) | ✅ | ✅ | `cdp/cloudflare.rs` / `browser/cloudflare.rs` |

## 2. 仅 CDP(默认后端)有

这批是 **Chromium 协议专有**:Firefox / Juggler 没有对应命令,故只在 CDP 后端实现(`src/cdp/extras.rs`
的「标配补齐」+ `src/cdp/` 的逆向套件)。

### 2.1 标配补齐(`src/cdp/extras.rs`)

| 能力 | CDP | Camoufox | 备注 |
|---|:---:|:---:|---|
| 移动端设备模拟 + 预设 | ✅ | — | `Device::iphone_13/iphone_se/ipad/pixel_7/galaxy_s9`;`device()` / `clear_device()` / `touch()` |
| 媒体模拟(`emulate_media` / `emulate_dark`) | ✅ | — | `Emulation.setEmulatedMedia`(打印 / 暗色 / reduced-motion 等) |
| 离线切换(`offline`) | ✅ | — | `Network` 域断网 |
| 网络条件模拟(`network_conditions`) | ✅ | — | 带宽 / 延迟 / 丢包;含 `slow_3g` / `fast_3g` 预设 |
| CPU 节流(`cpu_throttling`) | ✅ | — | `Emulation.setCPUThrottlingRate` |
| 权限授予 / 重置(`grant_permissions` / `reset_permissions`) | ✅ | — | `Browser.grantPermissions` |
| HAR 录制 + 回放(`har_record` / `route_from_har`) | ✅ | — | 录成 HAR、按 HAR 回放路由(离线重放) |
| 注入原生函数(`expose_function`) | ✅ | — | `Runtime.addBinding`,页面调 JS 回 Rust |
| 打印 PDF(`print_to_pdf` / `save_pdf`) | ✅ | — | `Page.printToPDF` + `PdfOptions` |
| 保存 MHTML(`mhtml` / `save_mhtml`) | ✅ | — | `Page.captureSnapshot` |
| 设置整页内容(`set_content`) | ✅ | — | 直接灌 HTML |
| 细粒度 storage(`local_storage_*` / `session_storage_*`) | ✅ | — | 单键 set/get/remove/clear |
| 原生无障碍树(`ax_tree`) | ✅ | — | `Accessibility.getFullAXTree`,来自 Chrome 无障碍引擎,**最准**(Camoufox 无 `Accessibility` 域,只能用 §1 的 DOM 派生 `ax_snapshot`) |

### 2.2 逆向套件(Chromium 协议专有)

| 能力 | CDP | Camoufox | 备注 |
|---|:---:|:---:|---|
| 调试器(`tab.debugger()`) | ✅ | — | `src/cdp/debugger.rs`:断点 / 变量 / 调用栈 |
| 反-反调试(`anti_anti_debug`) | ✅ | — | 压制 `debugger` 死循环等反调试陷阱 |
| 脚本管理(`tab.scripts()`) | ✅ | — | `src/cdp/scripts.rs`:枚举 / 抓取 / 定位源 |
| 运行时 Hook(`tab.hook()`) | ✅ | — | `src/cdp/hook.rs`:函数 / 属性 hook |
| 录制 → 生成代码(`ChromiumRecorder`) | ✅ | — | `src/cdp/recorder.rs`;codegen 核心后端无关,但录制采集当前只在 CDP |

## 3. 仅 Camoufox 有

Camoufox 端的差异化能力:图像滑块、服务器化、以及更细的指针 / 身份反检测与显式长监听生命周期。

| 能力 | CDP | Camoufox | 备注 |
|---|:---:|:---:|---|
| 滑块 / 缺口识别 + 拟人拖动 | — | ✅ | `src/browser/slider.rs`,需 `--features slider`;`slider_gap` / `solve_slider`,含 GeeTest / 顶象预设 |
| 浏览器服务器(`BrowserServer`) | — | ✅ | `src/browser/serve.rs`:拉起后暴露 Juggler WS 端点供接管 |
| 指针反检测(`apply_pointer_stealth`) | — | ✅ | 补 `movementX/Y` 等空值,过 GeeTest 类轨迹检测 |
| 显式长监听 / 拦截生命周期句柄 | — | ✅ | `listen_forever` / `listen_next` / `listen_stream` / `intercept_next` / `intercept_xhr`(CDP 只有 `listen()` / `intercept()` 构建器) |
| 更细的每标签身份覆盖 | — | ✅ | `ContextOverride` 额外支持 `os` / `geolocation` / `platform` / `window_size`(基础 `proxy` / UA / `locale` / 时区两端都能覆盖) |

## 4. 说明与选后端建议

- **逆向套件是 Chromium 协议专有**:调试器 / 反-反调试 / hook / 脚本管理 / 录制依赖 CDP 的 `Debugger`、
  `Runtime`、`Accessibility` 等域,Firefox / Juggler 无对等命令,故只在 CDP 后端提供。
- **滑块基于 Camoufox**:图像滑块与指针反检测长在 Camoufox 后端(`--features slider` 自动带上 `camoufox`)。
- **OCR 与无障碍语义快照后端无关**:`tab.ocr_image` + `set_default_ocr` 热替换、`ax_snapshot` 两端都有且行为一致;
  只有原生 `ax_tree` 是 CDP 专有。

**怎么选:**

- **默认选 CDP**(`default = ["cdp"]`):能力最全(标配补齐 + 逆向套件 + 原生无障碍树)、编译最精简,
  绝大多数抓取 / 自动化 / 逆向场景首选。
- **需要图像滑块 / 缺口识别,或某些 Firefox 指纹场景**时,用 Camoufox
  (`default-features = false, features = ["camoufox"]`,滑块再加 `slider`)。
- 两个后端不冲突,可按能力各取所需;共享类型始终编译,纯 CDP 构建不含任何 Camoufox 代码。
- **服务器上要更轻的无头吞吐、能接受无真渲染**时,同一套 CDP API 可切 Lightpanda:
  `BrowserOptions::new().lightpanda()`。不是第三套协议,也不是 `drs` 后端
  (`drs` 继续用本机 Chrome)。截图/PDF/Windows 原生弱或无。详见 [Lightpanda.md](Lightpanda.md)。
